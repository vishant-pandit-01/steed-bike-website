# STEED Bike Website

A modern and fully responsive motorcycle landing page website built with HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive Design
- Sticky Glassmorphism Navbar
- Smooth Scrolling Navigation
- Swiper.js Slider
- Modern UI/UX
- Remix Icons Integration
- Animated Sections
- Mobile Friendly Layout
- Social Media Footer Links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Swiper.js
- ScrollReveal.js
- Remix Icons

## 📸 Sections Included

- Hero Section
- Services Section
- About Section
- Motorcycle Showcase Slider
- Banner Section
- Footer Section
